# data-cleaning-project
SQL project for cleaning and preparing a layoffs dataset using MySQL Workbench.
## Project Overview
This project uses SQL in MySQL Workbench to clean and prepare a layoffs dataset for analysis.

## Cleaning Process
- Created staging tables to preserve the original data
- Removed duplicate records
- Standardized data values
- Handled null and blank values
- Reviewed the cleaned data

## Tools
- MySQL Workbench
- SQL

## Files
- `data_cleaning.sql` — SQL queries used in the project
- `layoffs.csv` — layoffs dataset
