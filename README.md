World Layoffs Data Cleaning Using MySQL

📌 Project Overview

This project focuses on cleaning and preparing a global layoffs dataset using SQL in MySQL Workbench. The primary objective is to improve data quality, eliminate inconsistencies, and ensure the dataset is accurate, consistent, and ready for further use.

🎯 Project Objectives

- Identify and remove duplicate records.
- Standardize inconsistent data values.
- Handle missing and blank values.
- Remove irrelevant records where necessary.
- Maintain data accuracy and consistency.
- Prepare a clean and reliable dataset.

🛠️ Tools & Technologies

- Database: MySQL
- Development Environment: MySQL Workbench
- Query Language: SQL

🔍 Data Cleaning Process

The project involved the following data cleaning steps:

1. Data Staging: Created staging tables to preserve the original dataset and perform cleaning operations safely.
2. Duplicate Removal: Identified and removed duplicate records to maintain data integrity.
3. Data Standardization: Standardized company names, industry categories, and date formats.
4. Handling Missing Values: Identified and addressed NULL and blank values where appropriate.
5. Data Validation: Reviewed the cleaned dataset to verify consistency and accuracy.

💡 Skills Demonstrated

✅ Project Outcome

Successfully cleaned and prepared the global layoffs dataset by removing duplicates, standardizing data, and addressing missing values. The resulting dataset provides a more reliable foundation for future data analysis.
